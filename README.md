# OpenVenture Click-Through

Concept demo of the OpenVenture investor app: onboarding, Marketplace, company profiles, the invest flow, the Portfolio Dashboard, the Ownership Timeline, Documents and Profile, plus a guided demo mode.

All companies, people and figures are fictional. OpenVenture Portal, LLC is not yet registered with the SEC or a FINRA member, and no securities are offered.

- Open `index.html` in any browser, or use the hosted link.
- Add `?device=phone` or `?device=laptop` to the link to choose the starting view.
- During the guided demo, the left and right arrow keys move between steps.
- `brand/` holds the redrawn logo, compass mark and app icon as SVGs.
